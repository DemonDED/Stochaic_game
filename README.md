Игра «Крэпс» (Терминал)

Простая консольная реализация классической игры в кости «Крэпс» (Craps), написанная на C.
Этот проект создан в учебных целях для отработки фундаментальных концепций языка C: генерация случайных чисел, перечисления (enums), функции и управляющие конструкции.
🎲 Как играть

    Игрок бросает две кости.

    Если первая сумма равна 7 или 11 — игрок выигрывает немедленно.

    Если первая сумма равна 2, 3 или 12 — игрок проигрывает немедленно.

    В остальных случаях сумма становится очками (point) игрока. Игрок продолжает бросать кости до тех пор, пока:

        не выпадет сумма, равная очкам → победа,

        или не выпадет сумма 7 → поражение.

🛠️ Компиляция и запуск

Вам понадобится компилятор C (например, gcc).
Склонируйте репозиторий и скомпилируйте:
bash

git clone https://github.com/DemonDED/Stochaic_game.git
cd Stochaic_game
gcc -o craps craps.c
./craps

📚 Что я изучил / продемонстрировал

    Использование rand() и srand() для генерации псевдослучайных бросков костей.

    Определение и использование enum для состояний игры (CONTINUE, WON, LOST).

    Разделение кода на переиспользуемые функции (rollDice).

    Простой игровой цикл с условной логикой.

    Базовый ввод/вывод через printf, puts.
